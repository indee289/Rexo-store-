
# Z-Index Scale

- z-0: Base content
- z-10: Badges (e.g., Notification Bell), Tooltips, internal floating elements
- z-20: Sticky internal headers, Tabs, Filters
- z-30: Dropdowns, Context Menus
- z-40: AppHeader, BottomNavigation (Main App Shell)
- z-50: Modals, Drawers, Overlays
- z-[60]: Toasts, Nested Modals
